# Сочетания клавиш

## Все сочетания niri

Win = Super; Alt+Shift переключает US/RU через XKB. Таблица сгенерирована из конфигов; обновление: `python3 tools/update-hotkeys.py`.

| Клавиши | Действие |
| --- | --- |
| `Win+Shift+Slash` | Подсказка сочетаний |
| `Win+Enter`, `Win+T` | Терминал: Kitty / fish / Starship |
| `Win+D` | Запуск приложения |
| `Win+Alt+L` | Блокировка экрана |
| `Win+Alt+S` | Переключить экранный диктор |
| `XF86AudioRaiseVolume` | Громкость +3% |
| `XF86AudioLowerVolume` | Громкость −3% |
| `XF86AudioMute` | Включить / выключить звук |
| `XF86AudioMicMute` | Включить / выключить микрофон |
| `XF86AudioPlay` | Медиаплеер: play-pause |
| `XF86AudioStop` | Медиаплеер: stop |
| `XF86AudioPrev` | Медиаплеер: previous |
| `XF86AudioNext` | Медиаплеер: next |
| `XF86MonBrightnessUp` | Яркость +5% |
| `XF86MonBrightnessDown` | Яркость −5%, минимум 1 |
| `Win+O` | Обзор окон |
| `Win+Q` | Закрыть окно |
| `Win+Left`, `Win+H`, `Win+WheelScrollLeft`, `Win+Shift+WheelScrollUp` | Фокус на колонке слева |
| `Win+Down`, `Win+J` | Фокус на окне ниже |
| `Win+Up`, `Win+K` | Фокус на окне выше |
| `Win+Right`, `Win+L`, `Win+WheelScrollRight`, `Win+Shift+WheelScrollDown` | Фокус на колонке справа |
| `Win+Ctrl+Left`, `Win+Ctrl+H`, `Win+Ctrl+WheelScrollLeft`, `Win+Ctrl+Shift+WheelScrollUp` | Переместить колонку влево |
| `Win+Ctrl+Down`, `Win+Ctrl+J` | Переместить окно вниз |
| `Win+Ctrl+Up`, `Win+Ctrl+K` | Переместить окно вверх |
| `Win+Ctrl+Right`, `Win+Ctrl+L`, `Win+Ctrl+WheelScrollRight`, `Win+Ctrl+Shift+WheelScrollDown` | Переместить колонку вправо |
| `Win+Home` | Первая колонка |
| `Win+End` | Последняя колонка |
| `Win+Ctrl+Home` | Перенести колонку в начало |
| `Win+Ctrl+End` | Перенести колонку в конец |
| `Win+Shift+Left` | Фокус на мониторе: left |
| `Win+Shift+Down`, `Win+Shift+J` | Фокус на мониторе: down |
| `Win+Shift+Up`, `Win+Shift+K` | Фокус на мониторе: up |
| `Win+Shift+Right`, `Win+Shift+L` | Фокус на мониторе: right |
| `Win+Shift+H` | Хотспот |
| `Win+Shift+Ctrl+Left`, `Win+Shift+Ctrl+H` | Перенести колонку на монитор: left |
| `Win+Shift+Ctrl+Down`, `Win+Shift+Ctrl+J` | Перенести колонку на монитор: down |
| `Win+Shift+Ctrl+Up`, `Win+Shift+Ctrl+K` | Перенести колонку на монитор: up |
| `Win+Shift+Ctrl+Right`, `Win+Shift+Ctrl+L` | Перенести колонку на монитор: right |
| `Win+Page_Down`, `Win+U`, `Win+WheelScrollDown` | Следующее рабочее пространство |
| `Win+Page_Up`, `Win+I`, `Win+WheelScrollUp` | Предыдущее рабочее пространство |
| `Win+Ctrl+Page_Down`, `Win+Ctrl+U`, `Win+Ctrl+WheelScrollDown` | Перенести колонку на следующее пространство |
| `Win+Ctrl+Page_Up`, `Win+Ctrl+I`, `Win+Ctrl+WheelScrollUp` | Перенести колонку на предыдущее пространство |
| `Win+Shift+Page_Down`, `Win+Shift+U` | Переместить рабочее пространство вниз |
| `Win+Shift+Page_Up`, `Win+Shift+I` | Переместить рабочее пространство вверх |
| `Win+1` | Открыть рабочее пространство 1 |
| `Win+2` | Открыть рабочее пространство 2 |
| `Win+3` | Открыть рабочее пространство 3 |
| `Win+4` | Открыть рабочее пространство 4 |
| `Win+5` | Открыть рабочее пространство 5 |
| `Win+6` | Открыть рабочее пространство 6 |
| `Win+7` | Открыть рабочее пространство 7 |
| `Win+8` | Открыть рабочее пространство 8 |
| `Win+9` | Открыть рабочее пространство 9 |
| `Win+Ctrl+1` | Перенести колонку на пространство 1 |
| `Win+Ctrl+2` | Перенести колонку на пространство 2 |
| `Win+Ctrl+3` | Перенести колонку на пространство 3 |
| `Win+Ctrl+4` | Перенести колонку на пространство 4 |
| `Win+Ctrl+5` | Перенести колонку на пространство 5 |
| `Win+Ctrl+6` | Перенести колонку на пространство 6 |
| `Win+Ctrl+7` | Перенести колонку на пространство 7 |
| `Win+Ctrl+8` | Перенести колонку на пространство 8 |
| `Win+Ctrl+9` | Перенести колонку на пространство 9 |
| `Win+BracketLeft` | Объединить / отделить окно слева |
| `Win+BracketRight` | Объединить / отделить окно справа |
| `Win+Comma` | Добавить соседнее окно в колонку |
| `Win+Period` | Отделить нижнее окно в колонку |
| `Win+R` | Следующая ширина колонки |
| `Win+Shift+R` | Предыдущая ширина колонки |
| `Win+Ctrl+Shift+R` | Следующая высота окна |
| `Win+Ctrl+R` | Сбросить высоту окна |
| `Win+F` | Развернуть колонку |
| `Win+Shift+F` | Полноэкранный режим |
| `Win+M` | Развернуть окно до краёв |
| `Win+Ctrl+F` | Занять свободную ширину |
| `Win+C` | Центрировать колонку |
| `Win+Ctrl+C` | Центрировать видимые колонки |
| `Win+Minus` | Ширина колонки -10% |
| `Win+Equal` | Ширина колонки +10% |
| `Win+Shift+Minus` | Высота окна -10% |
| `Win+Shift+Equal` | Высота окна +10% |
| `Win+Ctrl+V` | Плавающий / плиточный режим |
| `Win+Shift+V` | Переключить фокус между плавающими и плиточными окнами |
| `Win+W` | Вкладки / стопка в колонке |
| `Print` | Снимок выбранной области |
| `Ctrl+Print` | Снимок экрана |
| `Alt+Print` | Снимок окна |
| `Win+Escape` | Разрешить / запретить перехват горячих клавиш приложением |
| `Win+Shift+E`, `Ctrl+Alt+Delete` | Выйти из niri с подтверждением |
| `Win+Shift+P` | Погасить мониторы; любой ввод включает их снова |
| `Win+V` | История буфера обмена |
| `Win+Alt+V` | Действия с буфером обмена |
| `Alt+Tab`, `Win+Tab` | focus-window-previous |
| `Win+P` | Мониторы / HDMI / дублирование |
| `Win+Ctrl+P` | Включить экраны и восстановить автоматическое расположение |
| `Win+Alt+C` | Caffeine |
| `Win+N` | Центр уведомлений |
| `Win+Shift+N` | Вернуть последнее уведомление |
| `Win+Shift+C` | Календарь и заметки |
| `Win+Alt+T` | Таймер |
| `Win+B` | Zen Browser |
| `Win+G` | Telegram |
| `Win+X` | Центр управления |
| `Win+Shift+W` | Wi-Fi |
| `Win+Shift+B` | Bluetooth |
| `Win+Shift+A` | Аудиоустройства |
| `Win+Shift+Escape` | Питание |
| `Win+Shift+D` | Выбор обоев |
