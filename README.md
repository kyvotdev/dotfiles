# Pixel Shell

Dotfiles для Arch Linux + niri: тонкая панель 24 px, пиксельный Terminess в интерфейсе, Kitty с JetBrains Mono SemiBold, собственные меню, календарь и управление мониторами. Палитра меняется от обоев в диапазоне голубой–синий; фон графитовый. Зелёные и красные акценты исключены, предупреждения выделяются приглушённым жёлтым. Интерфейс программ — на английском.

## Установка и обновление

Все исходники, скрипты и обои находятся в этом репозитории. Установщик создаёт ссылки в `~/.config`, `~/.local/bin` и `~/Pictures/Wallpapers`. Конфликтующие файлы сохраняются в `backups/<дата>/`. При переносе на другую учётную запись установщик подставляет её домашний каталог в подготовленные конфиги. Не переноси вручную отдельные файлы вместо запуска install.py.

```bash
sudo pacman -Syu --needed niri waybar fuzzel kitty alacritty fish starship \
  networkmanager bluez bluez-utils python python-pillow python-dbus python-gobject gtk3 \
  wireplumber pipewire brightnessctl swaybg swayidle swaylock mako libnotify \
  playerctl wl-clipboard dnsmasq adw-gtk-theme qt5ct qt6ct papirus-icon-theme \
  ttf-terminus-nerd ttf-nerd-fonts-symbols-mono ttf-jetbrains-mono-nerd \
  xcursor-vanilla-dmz xwayland-satellite lxqt-policykit

# Только для функции дублирования экрана:
sudo pacman -S --needed wl-mirror

python3 ~/dotfiles/install.py
fc-cache -f
sudo systemctl enable --now NetworkManager bluetooth
~/.local/bin/pixel-activate
```

Перезайди в niri, чтобы применились переменные Qt и новые службы. `dnsmasq` используется NetworkManager для хотспота: отдельную службу dnsmasq включать не нужно. Zen Browser и Telegram устанавливаются отдельно; команды запуска — `zen-browser` и `telegram-desktop`.

При обновлении репозитория повтори `python3 ~/dotfiles/install.py` и `~/.local/bin/pixel-activate`. Скрипт не выполняет sudo и не перезагружает компьютер. Для fish как login shell при желании выполни `chsh -s /usr/bin/fish`.

## Календарь и заметки

`pixel-calendar` открывает отдельное плавающее окно с кликабельным календарём. Стрелки листают месяцы, Today возвращает текущую дату, поле Jump to date принимает YYYY-MM-DD. Дни с невыполненными заметками выделены жирным. Порядок дней недели определяется локалью GTK.

Справа находятся заметки выбранного дня: добавление, редактирование, отметка выполнения, удаление и Undo delete. Upcoming показывает незавершённые дела на ближайшие 30 дней. Текст заметки можно выделять и копировать обычным способом. Старые заметки из прежнего меню сохраняются и автоматически преобразуются при редактировании. Приложение не выполняет команд из текста заметок.

| В окне календаря | Действие |
| --- | --- |
| Esc | Закрыть |
| Ctrl+N | Перейти к новой заметке |
| Ctrl+L | Перейти к выбору даты |
| Enter в поле заметки | Добавить / сохранить |
| Enter в поле даты | Перейти к дате |

Данные лежат в `~/.local/state/pixel-shell/notes.json`, права файла 0600. Запись атомарная, с блокировкой от параллельных изменений. Ошибка чтения не перезаписывает исходный файл. Заметки и история уведомлений не попадают в Git.

## Мониторы и HDMI / DisplayPort

`pixel-displays` (Win+P) показывает подключённые выходы и предлагает:

- только встроенный экран;
- только выбранный внешний монитор, включая HDMI;
- расширение рабочего стола справа, слева, сверху или снизу;
- дублирование выбранного источника на другой экран;
- разрешение и частоту из режимов, объявленных монитором;
- масштаб, поворот, включение и отключение экрана;
- сохранение / восстановление расположения;
- включение всех экранов с автоматическим расположением.

Размещение учитывает **логические** размеры после масштабирования. Последний активный экран отключить через меню нельзя. После изменения появляется Keep / Revert с таймером 15 секунд; Escape и истечение времени возвращают предыдущие параметры. Независимый процесс дополнительно восстанавливает параметры, если главное меню аварийно завершилось (до 40 секунд от начала операции).

Настройки временные, пока не выбрано Save current layout. Сохранённая конфигурация — `config/niri/monitors.kdl`, она исключена из Git как локальная настройка оборудования. Служба `pixel-display-watch.service` включает встроенный экран, если после отключения внешнего не осталось активных выходов. Это не мешает обычному погашению экранов через DPMS.

**Дублирование** использует [wl-mirror](https://github.com/Ferdi265/wl-mirror): полноэкранное окно на целевом мониторе, захват через ext-image-copy-capture, сохранение пропорций. Это копия изображения, а не аппаратный clone mode; рабочий стол остаётся расширенным. Закрытие окна или Stop mirroring прекращает показ. Служба `pixel-mirror.service` действует до завершения сессии. Поддержка зависит от протоколов работающего композитора и драйвера; на реальном HDMI ещё нужна проверка.

```bash
pixel-displays                 # меню
pixel-displays status          # JSON с режимами и состоянием
pixel-displays stop-mirror     # остановить дублирование
pixel-displays rescue          # включить экраны, автоматические режимы/позиции
journalctl --user -u pixel-mirror.service -b
```

Если изображение пропало: подожди отката либо нажми **Win+Ctrl+P**. Не вводи вслепую постоянные output-конфиги.

## Caffeine и раскладка

Caffeine возвращён на штатный Waybar `idle_inhibitor` со стандартными Font Awesome значками чашки. Самодельного виджета и генерации иконки больше нет; Win+Alt+C и центр управления посылают сигнал штатному модулю.

Caffeine приостанавливает автоматическую блокировку через 5 минут и погашение через 10 минут. Чашка в панели показывает состояние; Win+Alt+C и центр управления переключают тот же режим. Состоянием управляет Wayland idle-inhibit; при перезапуске панели режим выключается.

Блокировка **перед suspend** выполняется отдельной службой `pixel-sleep-lock.service` и остаётся включённой даже при Caffeine. Режим не отключает сон по закрытию крышки или настройкам logind. Без Caffeine работают обычные таймауты 5/10 минут.

Индикатор US/RU — штатный модуль Waybar `niri/language`, с `format="{}"` и подписями `format-en` / `format-ru`. Он использует события niri, поэтому обновляется при переключении с клавиатуры и по клику. Всплывающая подсказка показывает полное название раскладки.

## Wi-Fi, Bluetooth, звук и питание

| Команда | Возможности |
| --- | --- |
| `pixel-control wifi` | Сети, подключение, сохранённые профили, отключение, забывание, скрытая сеть |
| `pixel-control hotspot` | Pixel-Link: старт, стоп, показ пароля, удаление профиля |
| `pixel-bluetooth` | Выбор адаптера, питание, сканирование, pair/connect/disconnect, trust/block/forget |
| `pixel-control audio` | Выбор вывода и микрофона, mute |
| `pixel-control power` | Lock, suspend, logout, reboot, shutdown |
| `pixel-control menu` | Общий центр управления |

Пароль Wi-Fi запрашивает `nmcli --ask` в оформленном терминале. Поддержаны обычные открытые/WPA-Personal сети и существующие enterprise-профили; новые 802.1X-профили с сертификатами создаются через nmcli отдельно.

Хотспот требует AP-режима адаптера, отключает обычный Wi-Fi на нём и использует отдельный uplink для интернета. Случайный пароль передаётся NetworkManager через D-Bus, а не аргументы процесса. При смене адаптера удали профиль Pixel-Link и создай заново.

BlueZ-агент поддерживает PIN, passkey, numeric comparison, входящее сопряжение и авторизацию сервисов. Видимость / входящее сопряжение включаются на 120 секунд отдельным пунктом. Trust не включается автоматически. После Pair выбери Connect. Передача файлов OBEX не реализована. На заблокированном экране запрос нужно повторить после разблокировки.

Автозапуск nm-applet отключён через `config/autostart/nm-applet.desktop`; сам NetworkManager остаётся включённым. В меню используются собственные SVG в отдельной колонке; они перекрашиваются вместе с темой.

## Уведомления и таймер

`pixel-extras notifications` показывает видимые уведомления и историю (до 100 записей в памяти Mako), действия приложения, копирование текста, восстановление и Do not disturb. Обычные уведомления видны 30 секунд, критические остаются до закрытия. Уведомления оформлены компактными карточками с читаемым JetBrains Mono, отдельными строками приложения/заголовка/текста, иконкой и группировкой повторов; критические выделены жёлтым контуром. Левый клик вызывает действие приложения, правый закрывает, средний открывает список действий приложения.

`pixel-extras timer`: 10/25/50 минут либо своё время 1–240 минут, отмена. Уведомление по окончании остаётся до закрытия. Таймер через user systemd действует в текущей пользовательской сессии. `pixel-extras calendar` и `pixel-extras notes` оставлены как совместимые команды для нового календаря.

## Обои, тема и терминал

```bash
pixel-wallpaper                # меню: выбрать, случайные, следующие, папка
pixel-wallpaper random
pixel-wallpaper next
pixel-theme /path/image.png    # применить изображение и палитру
pixel-theme --restore
pixel-theme --default          # стандартная палитра, обои остаются прежними
```

В наборе пять собственных обоев 1920×1080: тихая сетка, горы, ночной город, орбиты и дюны. Добавляй изображения в `assets/wallpapers/`, затем запускай install.py, либо клади их в `~/Pictures/Wallpapers`. Поддержаны PNG/JPEG/WebP через Pillow. Генераторы исходных обоев и SVG лежат в `tools/`.

Тема охватывает Waybar, niri, Fuzzel, Kitty, Alacritty, fish/Starship, GTK3/4, Qt5/6, Mako и swaylock. Niri, панель и терминалы обновляются автоматически; fish/Starship — со следующим prompt. Qt5/Qt6 используют общий ключ `QT_QPA_PLATFORMTHEME=qt6ct` (оба установленных плагина имеют совместимые имена). Параметры берутся из отдельных qt5ct/qt6ct-конфигов, Fusion и палитра пересоздаются при смене обоев; Qt6 дополнительно получает роль Accent. qtct отслеживает изменения конфигурации и обновляет совместимые открытые приложения примерно через 3 секунды. При первом исправлении переменной окружения нужно перезайти в niri и заново открыть Qt-приложения. GTK-приложения могут требовать перезапуск; приложения с собственной темой и Qt Quick могут игнорировать палитру. Flatpak требует отдельного доступа к теме. SDDM не настроен этим репозиторием.

Терминал — Kitty, JetBrainsMono Nerd Font Mono SemiBold 12 pt, непрозрачность фона 88% при любом фокусе, короткий шлейф курсора. Alacritty — запасной вариант с тем же шрифтом и прозрачностью. Подтверждение закрытия Kitty отключено. Пиксельный Terminess Bold 14 px используется в тонкой панели; его fontconfig-правило не затрагивает JetBrains Mono.

| В Kitty | Действие |
| --- | --- |
| Ctrl+Shift+C / V | Копировать / вставить |
| Ctrl+Shift+Minus / Equal | Уменьшить / увеличить шрифт |
| Ctrl+Shift+Backspace | Сбросить размер шрифта |
| Ctrl+Shift+F5 | Перечитать конфиг |

Fish: сокращения `ll`, `wifi`, `bt`, `hotspot`, `theme`; zoxide подключается, если установлен. Рекомендуемые необязательные инструменты: `btop eza bat fd ripgrep fzf zoxide yazi fastfetch jq`.

## Переключение окон и Neovim

Горизонтальный фокус niri плавно центрирует выбранную колонку (`center-focused-column always`). Для Win+Up/Down, Win+J/K и переходов между мониторами применяется короткий crossfade через `pixel-focus`; Alt+Tab и Win+Tab возвращают предыдущее окно с тем же эффектом. Это переход по клавишам; сам по себе статичный фокус в niri не имеет отдельной анимации перемещения окна. Длительность перемещения сцены задаётся spring-анимацией, рабочие столы меняются за 260 мс.

Добавлена готовая конфигурация **Neovim**, подключённая через install.py: [языки, установка инструментов и все клавиши](docs/NEOVIM.md). База запускается без скачивания плагинов; `:PixelInstall` добавляет mini.nvim, `:PixelTools` показывает отсутствующие серверы и форматтеры. Широкая языковая поддержка использует встроенный LSP; отдельные серверы/SDK устанавливаются под выбранные проекты. Внешние загрузки из среды редактора недоступны.

## NVIDIA T550

Подготовлен отдельный `bash ~/dotfiles/tools/install-nvidia.sh` для обнаруженной NVIDIA T550/Turing и linux-zen. Он устанавливает NVIDIA DKMS + headers, включает DRM modesetting и пересобирает initramfs. Это системная операция с sudo и полным обновлением Arch. Из среды редактора установка не выполнялась.

После успешной установки и перезагрузки: `pixel-gpu discrete`, затем перезайди в niri. `pixel-gpu status` показывает драйвер и сохранённый renderer; `pixel-gpu auto` отменяет выбор NVIDIA. Локальный `active-gpu.kdl` исключён из Git. Встроенный eDP подключён к Intel: NVIDIA рендерит, Intel выводит изображение; физический discrete-only зависит от наличия MUX/UEFI. Этот скрипт не переключает MUX и не отключает Intel.

## Проверки, данные и откат

```bash
pixel-doctor
niri validate
fuzzel --check-config
python3 -m unittest discover -s ~/dotfiles/tests -v
journalctl --user -u pixel-bluetooth.service -u pixel-idle.service \
  -u pixel-sleep-lock.service -u pixel-display-watch.service -b
```

Выполнены проверки конфигов и тесты миграции/сохранения заметок, выбора меню, отката мониторов, палитры и Bluetooth-кодов. GUI календаря, живые Wi-Fi/Bluetooth/HDMI и дублирование требуют проверки в пользовательской сессии: среда редактора не имеет доступа к её Wayland/D-Bus. Драйвер NVIDIA не считается установленным только на основании наличия скрипта.

Пользовательские данные и журналы — `~/.local/state/pixel-shell`; сетевые пароли — в NetworkManager, Bluetooth-пары — в BlueZ. Git исключает backups, local GPU/monitor profiles, кэш и загрузки шрифтов/курсоров.

Исходный niri сохранён локально в `backups/niri-original.kdl` (не публикуется в Git). Для его восстановления:

```bash
cp ~/dotfiles/backups/niri-original.kdl ~/dotfiles/config/niri/config.kdl
systemctl --user stop pixel-bluetooth.service pixel-idle.service \
  pixel-sleep-lock.service pixel-display-watch.service pixel-mirror.service
```

Для отката только расположения мониторов: `pixel-displays rescue`; для GPU: `pixel-gpu auto`. Конфликтующие файлы установщика можно восстановить из backups. Перед клонированием репозитория на другой компьютер проверь аппаратно-зависимый NVIDIA-скрипт.
